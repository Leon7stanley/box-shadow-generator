# Box Shadow Generator

A visual CSS box-shadow customization tool.

## Features

- Offset controls
- Blur and spread controls
- CSS code generation

## How to Use

Adjust the shadow settings and copy the generated CSS.

## Technologies

- HTML
- CSS
- JavaScript

## Running Locally

Open `index.html` in a modern web browser.
## Manual Testing Checklist

- [ ] Adjust horizontal and vertical shadow offsets.
- [ ] Change the blur radius and inspect the preview.
- [ ] Copy the CSS and compare it with the displayed settings.
